# NextStudio User Manual

Welcome to the NextStudio User Manual. It explains how to set up the application, create and manage projects, work with audio and MIDI, and use the built-in instruments and effects.

NextStudio is currently alpha software. Features and project compatibility may change. Keep independent backups of important projects and source audio.

## About this manual

This manual is generated from the English Markdown documentation stored with the NextStudio source code. The website is a presentation of that documentation, not a separate copy.

Developer architecture, component contracts, build instructions, plans, and historical records remain available in the [NextStudio repository](https://github.com/BaraMGB/NextStudio/tree/main/docs), but are intentionally excluded from this user manual.
