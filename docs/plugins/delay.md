# Delay

## Overview

| Property | Value |
|---|---|
| Type ID | `next_delay` |
| Category | Effect |
| Channels | Mono, Stereo |
| Delay Range | 20–2000 ms |

## Controls

| Parameter | Range / Options | Description |
|---|---|---|
| Mode | Mono, Stereo, Ping Pong, Dual | Delay routing mode |
| Sync | On / Off | BPM sync toggle |
| Time | 20–2000 ms | Delay time (when sync off) |
| Synced Time | 1/32 – 1/1 | Delay time in note values (when sync on) |
| Feedback | 0–95% | Amount of delayed signal fed back |
| Mix | Dry–Wet | Dry/wet ratio |
| Stereo Offset | 0–100 ms | Additional time difference between L and R channels |
| Ping Pong Amount | — | Intensity of ping-pong behaviour in Ping Pong mode |
| HP Cutoff | — | Highpass filter in the feedback path |
| LP Cutoff | — | Lowpass filter in the feedback path |
