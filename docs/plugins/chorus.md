# Chorus

## Overview

| Property | Value |
|---|---|
| Type ID | `next_chorus` |
| Category | Effect |
| Channels | Stereo (max 2 outputs) |
| Base Delay | 20 ms (fixed) |

## Controls

| Parameter | Range | Description |
|---|---|---|
| Depth | 0–30 ms | Modulation depth of the delay time |
| Speed | 0.02–10 Hz | LFO modulation speed |
| Width | — | Stereo width of the chorus effect |
| Mix | Dry–Wet | Dry/wet ratio |
