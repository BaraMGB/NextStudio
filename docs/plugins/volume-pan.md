# Volume & Pan

## Overview

| Property | Value |
|----------|-------|
| Type ID | `volume` |
| Category | Effect |
| Channels | Mono and stereo |
| Engine | Tracktion Engine built-in Volume and Pan parameters |

Simple gain staging element. Can be placed at any point in the effect chain.

## Controls

| Parameter | Range | Description |
|-----------|-------|-------------|
| Volume | dB | Output gain |
| Pan | L/R | Stereo pan position |
