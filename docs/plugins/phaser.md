# Phaser

## Overview

| Property | Value |
|---|---|
| Type ID | `next_phaser` |
| Category | Effect |
| Channels | Stereo (max 2 outputs) |
| Engine | JUCE DSP engine |

## Controls

| Parameter | Range | Description |
|---|---|---|
| Depth | 0–1.0 | Modulation depth of the all-pass filter sweep |
| Rate | 0.02–10 Hz | LFO modulation speed |
| Feedback | −0.95 to +0.95 | Regeneration amount; negative values invert the phasing character |
| Mix | Dry–Wet | Dry/wet ratio |
