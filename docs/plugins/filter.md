# Filter

## Overview

| Property | Value |
|---|---|
| Type ID | `next_filter` |
| Category | Effect |
| Channels | Mono, Stereo |
| Default | Lowpass, 1400 Hz, 24 dB/oct |

## Controls

| Parameter | Range | Description |
|---|---|---|
| Frequency | 20–20000 Hz | Cutoff frequency |
| Resonance | 0.3–6.0 | Emphasis at the cutoff point |
| Mode | Lowpass / Highpass | Filter topology |
| Slope | 12, 24, 36, 48 dB/oct | Steepness of the filter roll-off |
