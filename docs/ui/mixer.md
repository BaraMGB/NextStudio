# Mixer

## Overview

The Mixer provides a traditional mixing console view in the Lower Zone. It shows one channel strip per audio track, plus a Master channel at the end. Accessible via the Mixer tab in the Lower Zone sidebar.

## Channel Strip Layout

Each channel strip shows:

| Element | Description |
|---|---|
| Track Name | Shows the track name with colored background (matches track color) |
| Volume Fader | Vertical slider for volume control (drag up/down) |
| Pan Knob | Horizontal slider for stereo panning (left/right) |
| Level Meters | Two vertical meters showing left and right channels in real-time |
| Mute (M) | Mutes the track (button highlighted when active) |
| Solo (S) | Solos the track (other tracks are muted) |
| Record (R) | Arms the track for recording (audio tracks only) |

## Master Channel

The last channel strip is always the **Master Track**:

- Controls overall volume and panning.
- Has Mute button (no Solo or Record buttons).
- Level meters show the final output signal.

## Navigation

- Channel strips are arranged horizontally.
- With many tracks, a horizontal scrollbar appears.
